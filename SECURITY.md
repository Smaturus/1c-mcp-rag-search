# Политика безопасности

## Поддерживаемые версии

Проект учебный и развивается в `main`. Патчи безопасности выходят в последнюю
версию (`0.2.x`); старые версии отдельно не поддерживаются.

## Как сообщить об уязвимости

**Не открывайте публичный issue с описанием уязвимости.**

- Предпочтительно — приватно через GitHub:
  вкладка **Security → Report a vulnerability** в этом репозитории;
- Либо письмом на **smaturus@gmail.com** с темой `[security] 1c-mcp-rag-search`.

Пожалуйста, приложите версию/коммит, шаги воспроизведения и оценку влияния.

**Что ожидать:** подтверждение получения в течение 72 часов, первичная оценка —
до 14 дней, затем согласование сроков исправления и упоминание автора отчёта
(если он этого хочет).

## Что входит в область

- Код MCP-сервера и retrieval-пайплайна (`src/mcp_1c_homework/`).
- Скрипты сборки индексов, eval и бенчмарков (`scripts/`).
- CI-конфигурация и зависимости проекта.

## Что НЕ входит

- Выгрузки конфигурации 1С, локальные индексы Chroma/BM25 и любые данные
  пользователя — они не публикуются в репозитории.
- Уязвимости сторонних библиотек (chromadb, sentence-transformers, flashrank,
  MCP SDK) — сообщайте их мейнтейнерам; мы отслеживаем их через Dependabot.
- Кэш HuggingFace и локальные модели.

## Модель угроз

Проект — локальный stdio-сервер: сетевых портов не открывает, внешних API не
вызывает, документы и индексы остаются на машине пользователя. Единственный
внешний контакт — загрузка моделей (e5-small, reranker) с HuggingFace при первом
запуске и установка зависимостей из PyPI.

Основные риски: недоверенные входные данные при индексации чужой выгрузки
1С (HTML/текст не исполняется), а также уязвимости в зависимостях.

## Меры защиты

- **Secret scanning** и **push protection** включены (публичный репозиторий).
- **Dependabot alerts** и автообновления зависимостей — см. `.github/dependabot.yml`.
- **CodeQL** для Python (GitHub default setup).
- Личные данные (резюме, вакансии, заметки) исключены через `.gitignore`;
  в истории коммитов секретов нет.
