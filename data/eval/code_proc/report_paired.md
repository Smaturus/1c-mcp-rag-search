## Метод

- Источник: 4 прогонов по шаблону `data/eval/code_proc/run_hybrid_*.json` (run_hybrid_1.json, run_hybrid_2.json, run_hybrid_3.json, run_hybrid_4.json).
- Значения метрики сначала усредняются по запросам между прогонами, затем режимы сравниваются парно — так убирается шум HNSW между прогонами.
- Bootstrap: 10000 ресэмплингов пар запросов, seed=42, percentile-интервал; p-value = 2·min(P(Δ*≤0), P(Δ*≥0)).
- Основные тесты: paired t-test (scipy.stats.ttest_rel) и bootstrap CI/p.
- Раньше в обзоре указывали p ≈ 0.154 — это тот же результат в пределах seed/метода bootstrap
  (здесь bootstrap p = 0.1594).
- Для сравнения, одиночный `report_pipeline.json` (run_hybrid_4), режим `--report`:
  Δ = +0.0411, CI [−0.0125; +0.0924], t-test p = 0.135, bootstrap p = 0.126 — не primary,
  но направление и незначимость те же.
- Wilcoxon (справочно, НЕ основной тест): p = 0.0448, нулевых Δ = 33/70, ненулевых = 37. При таком числе ничьих `zero_method='wilcox'` отбрасывает их и занижает p — как вывод не используется.
- Cohen's dz = mean(Δ) / sd(Δ), sd по выборке (ddof=1): 0.2179.

Δ > 0 означает, что `vector` лучше `hybrid`; Δ < 0 — наоборот.
