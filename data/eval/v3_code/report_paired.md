## Метод

- Источник: 3 прогонов по шаблону `.tmp/v3_prod_run*/report_pipeline.json` (report_pipeline.json, report_pipeline.json, report_pipeline.json).
- Значения метрики сначала усредняются по запросам между прогонами, затем режимы сравниваются парно — так убирается шум HNSW между прогонами.
- Bootstrap: 10000 ресэмплингов пар запросов, seed=42, percentile-интервал; p-value = 2·min(P(Δ*≤0), P(Δ*≥0)).
- Основные тесты: paired t-test (scipy.stats.ttest_rel) и bootstrap CI/p.
- Wilcoxon (справочно, НЕ основной тест): p = 0.6133, нулевых Δ = 30/71, ненулевых = 41. При таком числе ничьих `zero_method='wilcox'` отбрасывает их и занижает p — как вывод не используется.
- Cohen's dz = mean(Δ) / sd(Δ), sd по выборке (ddof=1): 0.1713.

Δ > 0 означает, что `vector` лучше `hybrid`; Δ < 0 — наоборот.
