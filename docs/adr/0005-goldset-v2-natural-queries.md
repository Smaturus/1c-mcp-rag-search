# ADR 0005: Gold-set v2 — естественные формулировки

- **Статус:** принято
- **Дата:** 2026-10-21
- **Контекст:** внешнее ревью отметило слабые абсолютные метрики. Причина была
  двойной: (а) 20 из 30 запросов v1 генерировались шаблоном «как реализовано
  документ …» — неестественная формулировка; (б) e5-small не обучен на коде.
  Вторая часть — отдельный контур (смена модели), первая — методическая.

## Решение

Собрать **gold-set v2**: 70 запросов в естественных формулировках.
- 30 курируемых доменных вопросов («как начислить НДС с авансов полученных»,
  «где рассчитывается НДС к вычету с авансов», «печать этикеток и штрихкодов»);
  файлы-эталоны разрешаются по реальному индексу.
- 40 запросов по реальным объектам конфигурации с естественными шаблонами
  («как проводится документ …», «как формируется отчёт …») вместо
  «как реализовано документ …».

Релевантность — по уникальным файлам-источникам (ADR 0003–0004), mean ± std
по трём независимым прогонам.

## Результаты (30 → 70 запросов)

| Конфигурация | v1 nDCG@10 | **v2 nDCG@10** | v1 MRR@10 | **v2 MRR@10** | v1 Hit@1 | **v2 Hit@1** |
|---|---|---|---|---|---|---|
| `vector` | 0.143 | **0.176 ± 0.005** | 0.109 | 0.127 | 0.022 | 0.076 |
| `pearson` | 0.165 | **0.194 ± 0.006** | 0.148 | 0.139 | 0.078 | 0.090 |
| `hybrid` | 0.199 | **0.209 ± 0.003** | 0.183 | 0.158 | 0.100 | 0.090 |
| `hybrid_rerank` | 0.078 | **0.069** | 0.048 | 0.047 | 0.000 | 0.014 |

## Выводы

1. **Абсолютные метрики выросли** (vector nDCG@10 0.143 → 0.176, Hit@1 0.022 →
   0.076): запросы стали ближе к реальным формулировкам разработчика.
2. **Разрыв hybrid над vector сократился**: nDCG@10 +39 % на v1 → **+19 %**
   на v2, MRR +68 % → +24 %. На естественных запросах semantic-baseline
   работает лучше, и вклад лексического сигнала меньше. Это не отменяет выбор
   hybrid (он по-прежнему лучший), но честно уменьшает заявленный эффект.
3. **Reranker проигрывает и на v2** (0.069 против 0.209), вывод ADR 0002
   устойчив к смене набора.
4. **Ограничение:** авточасть v2 — шаблонная, хотя и построена по реальным
   именам объектов; в запросах встречаются слова из имени файла, что может
   давать лёгкую утечку. Курируемая часть (30 запросов) написана вручную.
   Следующий шаг — ручная разметка 100+ запросов и отдельная оценка согласия
   разметчиков.

## Последствия

- v2 — основной набор для отчётов; v1 сохранён как исторический
  (`data/eval/gold_set.jsonl`).
- Скрипт: `scripts/make_goldset_v2.py`, отчёты: `data/eval/v2/`.
- В README Evaluation показывает v2, сравнение с v1 — в таблице выше.
